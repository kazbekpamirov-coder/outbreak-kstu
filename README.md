# Outbreak at KSTU

A zombie survival game about cybernetics and system thinking, made for the presentation
“Cybernetics and System Thinking” by Kazbek Pamirov (KSTU named after I. Razzakov, group BIS-1-26).

**Play:** https://kazbekpamirov-coder.github.io/outbreak-kstu/

Six rounds, each built on one idea from cybernetics:

1. Panic in the corridors — reinforcing feedback loops
2. The siege and the black box — the black box method
3. The canteen — open systems (Bertalanffy)
4. The delayed radio — delays in feedback
5. Night attacks — leverage points (Meadows)
6. Boss fight: Professor Z — Ashby's law of requisite variety

Keys for the presenter: A / B choose · V 15-second vote · N speaker notes · M sound · F full screen · 1–6 jump to a round.
The page is a single self-contained `index.html`; all sounds are generated in the browser.
